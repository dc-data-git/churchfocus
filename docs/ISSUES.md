## Decisions from the walkthrough (4:14 pm →)
- D26 · A1 · Deep-dive fix = `reasoning_effort="none"` on chat_tools only; no Responses API move. (U15)
- D27 · C1 · Back end stays formulaic; the bot never asks the person to choose want/avoid/don't-care. It infers stance and strength from the conversation into a **user memory file**: an append-only, machine-readable change log (assumption → evidence → revision → reason). The current profile is computed from the log. The person can see and correct it; every change is recorded, never overwritten.
- D28 · C1/C3 · At the first search nothing is eliminated for practice/belief preferences — they only move fit (e.g. "must have charismatic worship" keeps an Anglican church, but at low fit, because Anglican worship is liturgical). Hard filtering only at the denomination level (the person explicitly excludes a denomination/tradition).

- D31 · Fit scale wording: Strong fit · Possible fit · Unlikely fit · Poor fit, plus "Not enough info yet" sorted after Possible.
- D32 · "What I know about you" side panel: current profile in plain words, every item editable; edits are logged as user corrections in the memory file.
